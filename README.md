Программа для сборки DJ-сета из папки с треками. Определяет темп, ключ и энергию каждого трека, расставляет треки так, чтобы они плавно сводились, и записывает порядок в сами файлы — Rekordbox, Serato и любой плеер видят его без этой программы.

Интерфейс на 15 языках: English, Español, Português, Français, Deutsch, Italiano, Polski, Русский, Türkçe, العربية, हिन्दी, Bahasa Indonesia, 中文, 日本語, 한국어.

## Установка

### ⬇️ [Скачать установщик ProDJTools-Setup.exe](https://github.com/EgaNet1/ProDJ-Tools/releases/latest)

1. На странице последнего релиза скачайте `ProDJTools-Setup-<версия>.exe` из раздела **Assets**.
2. Запустите его. Права администратора не нужны: программа ставится для текущего пользователя в `%LOCALAPPDATA%\Programs\ProDJ Tools`. Ярлык появится в меню «Пуск», по желанию — и на рабочем столе.
3. Установщик не подписан сертификатом, поэтому Windows SmartScreen может показать «Система Windows защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**.

Без установки: на той же странице лежит переносной `ProDJTools.exe` — его достаточно положить в любую папку и запустить.

Новая версия ставится поверх старой, настройки и кэш анализа сохраняются. Удаление — через «Параметры → Приложения». Деинсталлятор спросит, удалить ли кэш и настройки; папки с музыкой он не трогает.

**Требования:** Windows 10 или 11 (64-бит). Окно программы открывается через Microsoft Edge, который уже есть в Windows, или через Chrome.

## Запуск

Откройте ProDJ Tools из меню «Пуск». Откроется отдельное окно (Edge или Chrome в режиме приложения). Программа завершается сама, когда окно закрыто.

Поддерживаются FLAC, MP3 и WAV. Теги записываются в FLAC и MP3.

**Язык** при первом запуске выбирается по языку Windows; сменить его можно кнопкой с глобусом в правом верхнем углу. Переключение происходит сразу, без перезапуска: переводятся и интерфейс, и подсказки к переходам, и лист меток, и журнал экспорта.

## Что умеет

**Сет**
- Анализ папки на всех ядрах процессора; результаты кэшируются, поэтому повторное открытие занимает доли секунды.
- Порядок можно менять перетаскиванием. Замок оставляет трек на месте при пересборке, «−» убирает трек из сета.
- Между треками видна оценка перехода: изменение темпа в процентах и совместимость ключей (зелёный, жёлтый или красный).
- «Слушать стык» проигрывает конец одного трека и начало следующего, подогнанного по темпу, с плавным кроссфейдом.

**Сведение** — метки для подготовки сета, как у профессиональных диджеев
- Бит-сетка каждого трека: темп с точностью до тысячных BPM, первая сильная доля до долей миллисекунды. Показана точность сетки (обычно ±0,3–2 мс).
- Структура по тактам — интро, дропы, брейки, аутро — и метки на их сильных долях: A MIX IN, B DROP, C BREAK, D DROP 2, E MIX OUT.
- План каждого перехода по фразам: где в треке A запустить трек B, где поменять бас (дроп B совпадает с границей фразы A) и когда A полностью выведен — со временем мин:сек.мс и номером такта.
- «Прослушать» проигрывает переход ровно по плану: B стартует точно на такте, подогнан по темпу, бас меняется на сильной доле.
- Лист меток сохраняется в текстовый файл. При экспорте сетка и метки попадают в Rekordbox XML (hot cue и memory cue).

**Инструменты**
- **Кривая энергии** — форма сета: «Разгон», «Арка», «Волны», «Плато», «Остывание». По кривой выстраиваются и энергия, и темп.
- **Приоритеты** — что важнее при сборке: гармония ключей, плавность темпа или следование кривой.
- **Сет по времени** — выбирает из папки лучшие треки под слот заданной длины с учётом перекрытия при сведении.
- **Что поставить дальше** — лучшие продолжения для выбранного трека и колесо Камелота со всеми ключами папки.
- **Проверка переходов** — список мест, где сведение потребует внимания, с подсказками.
- **Октава темпа** — указывает, в каком диапазоне живёт ваш жанр, чтобы 70 и 140 BPM не путались.

**Экспорт**
- Нумерация файлов («07 - Artist - Title.flac»), номер в тегах, плейлисты M3U8 и Rekordbox XML.
- Перед первой записью исходные имена и теги сохраняются в `.prodj-backup.json`; кнопка «Вернуть файлы как было» откатывает изменения.

**Плеер** — регулятор громкости в нижней панели действует и на прослушивание треков, и на стыки; уровень запоминается между запусками.

Клавиши: `Пробел` — пауза, `↑` `↓` — выбор трека, `Enter` — играть, `L` — замок, `Del` — убрать из сета, `M` — выключить и включить звук.

## Сборка из исходников

Нужны только Windows 10/11, PowerShell и git. Go устанавливать не надо: при первом запуске скрипты сами скачают нужную версию (из `go.mod`) в папку `.goenv` проекта и проверят её контрольную сумму. Это аналог виртуального окружения Python — в систему ничего не устанавливается.

```powershell
git clone https://github.com/EgaNet1/ProDJ-Tools.git
cd ProDJ-Tools
.\build.ps1                          # проверки, тесты и сборка ProDJTools.exe
.\build-installer.ps1                # то же + установщик dist\ProDJTools-Setup-<версия>.exe
.\build-installer.ps1 -Version 1.2.0 # явно указать версию (по умолчанию — из файла VERSION)
```

Если Windows запрещает запуск скриптов, выполните один раз `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

Номер версии хранится в файле [VERSION](VERSION) и попадает в свойства exe, в установщик и в шапку программы рядом с логотипом. Иконка лежит в [assets/](assets/); её рисует скрипт `go run assets/genicon.go`.

Установщик собирается [Inno Setup 6](https://jrsoftware.org/isinfo.php) по сценарию [installer/ProDJTools.iss](installer/ProDJTools.iss). Если Inno Setup не установлен, `build-installer.ps1` скачает его в папку `.tools` проекта и проверит цифровую подпись.

Для работы с кодом вручную:

```powershell
. .\activate.ps1       # подключить Go из .goenv в текущем окне PowerShell
go test ./...
go run ./cmd/prodj -no-window -port 8080   # сервер без окна, интерфейс: http://127.0.0.1:8080
deactivate
```

### Выпуск версии

Сборка в GitHub Actions ([.github/workflows/build.yml](.github/workflows/build.yml)) проверяет каждый push. Чтобы выпустить релиз, впишите новую версию в `VERSION`, закоммитьте и поставьте тег с тем же номером:

```powershell
git tag v1.0.1
git push origin main v1.0.1
```

Actions соберёт установщик и переносной exe и опубликует их в [Releases](https://github.com/EgaNet1/ProDJ-Tools/releases). Ссылка «Скачать» в начале этого файла всегда ведёт на последний релиз.

## Устройство

```
cmd/prodj/            точка входа: сервер и окно
internal/
  audio/              декодирование FLAC/MP3/WAV сразу в моно ~11 кГц
  analysis/           темп (автокорреляция спектрального потока), бит-сетка (наложение
                      всех долей трека на одну), сильная доля, структура по тактам,
                      ключ (хромаграмма и профили Крумхансла–Кесслер), энергия
  mixplan/            метки A–E, план переходов по фразам, лист меток
  camelot/            ключи на колесе Камелота и их совместимость
  library/            параллельное сканирование папки, кэш, относительная энергия
  setlist/            кривые, оценка переходов, оптимизатор порядка, подсказки
  export/             нумерация, теги, плейлисты, резервная копия и откат
  tags/               чтение и запись тегов FLAC и MP3
  naming/             номера в именах файлов и названиях
  safefile/           атомарная перезапись и переименование с повтором
  desktop/            окно приложения и системный диалог выбора папки
  i18n/               переводы: выбор языка и подстановка сообщений
  server/             HTTP API между интерфейсом и движком
web/                  интерфейс (HTML, CSS, JS без фреймворков), встраивается в exe
  i18n/               тексты на каждом языке — общие для интерфейса и программы
assets/               иконка и скрипт, который её рисует
installer/            сценарий установщика Inno Setup
```

**Как собирается порядок.** Каждому варианту порядка назначается «стоимость»: скачки темпа, конфликты ключей, отклонение энергии и темпа от выбранной кривой, движение темпа против кривой. Минимум ищется имитацией отжига. Программа начинает со случайного порядка, переставляет треки, всегда принимает улучшения и иногда — ухудшения, всё реже со временем, чтобы не застрять в первом приемлемом варианте. Поиск идёт параллельно на всех ядрах, побеждает лучший результат. Сет из 30 треков собирается примерно за 30 мс.

**Как строится бит-сетка.** Отдельный удар в плотном миксе трудно поймать точно: атаки есть у баса, хэтов и синтов. Поэтому весь трек «складывается» на одну долю — каждый момент прибавляется к своей позиции внутри доли. При точном темпе атаки сотен долей ложатся в одну точку, а при ошибке в тысячные BPM размазываются. Так находится темп, а сложенная атака (среднее всех ударов трека) даёт фазу с точностью до сэмпла. Сильная доля определяется по тому, где в такте звук нарастает сильнее всего: новые партии и дропы входят на «раз».

**Как добавить язык.** Скопируйте [web/i18n/en.json](web/i18n/en.json) в `web/i18n/<код>.json`, переведите значения (ключи и `{0}`, `{1}` не трогайте) и впишите код в список `codes` в [internal/i18n/i18n.go](internal/i18n/i18n.go). `go test ./...` проверит, что переведены все сообщения и совпадают подстановки.

**Где хранятся данные.** Кэш анализа, настройки и журнал лежат в `%LOCALAPPDATA%\ProDJTools`. Порядок сета для каждой папки запоминается в окне программы.
